프로젝트 개요

고객 문의를 유형별로 정리하고 핵심 내용을 요약해 답변 초안을 제안하는 웹 도구를 가정한 예시 프로젝트입니다.

담당 역할 예시

  • 문의 유형과 요약 형식을 위한 프롬프트 설계
  • 사용자가 문의를 입력하고 결과를 확인하는 화면 구성
  • 모델 응답을 웹 화면에 전달하는 흐름 구현

구현 흐름 예시

  • 문의 내용을 입력받아 Azure OpenAI에 전달
  • 문의 유형과 요약, 답변 초안을 구조화해 생성
  • Django 웹 화면에서 생성 결과를 확인할 수 있도록 구성

사용 기술 예시

  • Python
  • Azure OpenAI
  • Django

결과 예시

문의 내용을 분류하고 답변 초안을 확인하는 업무 지원 프로토타입을 구현하는 것을 목표로 합니다.
