Azure ML 기반 이미지 분류 서비스

4인 팀 프로젝트

프로젝트 개요

전이학습을 활용한 이미지 분류 서비스를 만들고, 데이터 준비부터 모델 학습과 배포까지의 흐름을 Azure ML 파이프라인으로 자동화한 팀 프로젝트입니다.

담당 역할

  • 이미지 분류에 사용할 데이터 정제
  • 모델 학습 파이프라인 구성
  • 전이학습 기반 이미지 분류 모델 개발 과정에 참여

구현 흐름

  • 학습에 사용할 데이터를 정제하고 모델 입력 형태로 준비
  • 전이학습을 활용해 이미지 분류 모델을 학습
  • Azure ML 파이프라인으로 학습부터 배포까지 이어지는 작업을 자동화

사용 기술

  • Python
  • Azure ML
  • 전이학습

결과

모델 학습부터 배포까지의 과정을 Azure ML 파이프라인으로 자동화했습니다.
