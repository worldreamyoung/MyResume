사내 문서 Q&A RAG 챗봇

4인 팀 프로젝트

프로젝트 개요

사내 문서에서 질문과 관련된 정보를 찾아 답변에 활용하고, 답변에 근거 문서를 함께 제공하는 웹 챗봇입니다.

담당 역할

  • RAG 기반 문서 검색 기능 구성
  • 검색 결과를 바탕으로 답변을 생성하는 프롬프트 설계

구현 흐름

  • 사용자 질문과 관련된 사내 문서를 검색
  • 검색된 문서 정보를 Azure OpenAI 답변 생성에 활용
  • Django 웹 애플리케이션에서 질문과 근거가 포함된 답변을 제공

사용 기술

  • Azure OpenAI
  • Azure AI Search
  • Django
  • RAG

결과

문서 근거와 함께 답변하는 웹 챗봇을 완성했습니다.
